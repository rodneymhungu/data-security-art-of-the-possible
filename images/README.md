# Images

Every image here is a slide rendered from `data-security-art-of-the-possible-purview.pdf`. The slide content is Microsoft's; see the credits on the landing page. `manifest.json` lists each file with its page number, the section that uses it, its size and any crop.

When the PDF is replaced, re-render these from the new PDF at the same sizes and check that the page numbers in `manifest.json` and in the data block at the top of `index.html` still point at the right slides.
